# FoodFusion Express

Design a premium, modern, responsive Online Food Ordering Website called "FoodFuison".

The website should look like a professional startup product with a clean, elegant UI inspired by Swiggy, Zomato, and Uber Eats while maintaining its own unique identity.

Theme:

• Primary Color: sunset orange

• Secondary Color: golden yellow

• Accent Color: emrald green & royal purple

• Background: deep navy

• Use glassmorphism where appropriate.

• Rounded cards (18-24px)

• Soft shadows

• Smooth animations

• Modern typography

• Attractive illustrations

• Responsive for Desktop, Tablet and Mobile.

Currency:

Display every price in Indian Rupees (₹).
