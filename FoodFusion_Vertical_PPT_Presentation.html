Tech Stack & USP

Libraries & Technologies Used

  • Frontend UI: React 19, TypeScript, TanStack Router
  • AI Assistant: Floating AI Delivery Support Bot Engine
  • Backend REST API: Python 3.11 (FastAPI / Flask server.py)
  • Server Engine: TanStack Start / Nitro SSR Engine
  • Database & Auth: Supabase Database SDK + Local Persistence Store
  • Payments: Razorpay Sandbox Payment Portal

Existing Projects vs Food Fusion USP

  • Existing Platforms (Zomato / Swiggy):
    • Restricted to 1 hotel per order (double delivery fees).
    • Manual bill calculations during group dining.
  • Food Fusion USP:
    • Multi-Hotel Single Cart: Order from 2+ hotels in 1 checkout.
    • AI Group Room & QR Code: Automated bill splitter per member.
    • 3D SVG Fortune Wheel: Instant coupon unlocks.

Key Unique Features & Innovations

🍕 1. Multi-Hotel Single Cart Engine

Combine dishes from multiple partner restaurants in 1 single checkout. Saves ₹39+ per extra hotel on delivery fees.

🤖 2. AI Delivery Support Chatbot

Floating interactive AI assistant providing real-time order tracking, coupon help & instant resolution.

👥 3. AI Group Order Room & QR Bill Splitter

Friends scan QR code (FF-ROOM-9821) from their phones to join room and view individual bill splits.

🎡 4. Gamified 3D Vector Fortune Wheel

Interactive 3D SVG spin wheel with food sticker emojis & bonus spin credits awarded on food orders.

🔍 5. Double-Click 300% HD Image Zoom Lightbox

Full-screen 300% zoom controls for food dish photography before adding to cart.

🥦 6. Instant Pure Veg vs Non-Veg Mode

One-click dietary filter with green Pure Veg badges and 1000px Ultra-HD photos.

🐍 7. Python Full-Stack REST API Service

Python 3.11 backend service (server.py) serving AI meal recommendations & savings math algorithms.
