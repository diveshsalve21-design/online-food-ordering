🛵 6. ORDER TRACKING & RIDER HASHING — src/routes/orders.tsx
Presenter: Divesh Salve

Role: Displays order history, live status timeline, and dynamically assigned delivery rider.

function getRiderForOrder(orderId: string) { let hash = 0; for (let i = 0; i < orderId.length; i++) { hash = orderId.charCodeAt(i) + ((hash << 5) - hash); } const index = Math.abs(hash) % RIDERS.length; return RIDERS[index]; }

Rider Assignment: Hashes unique orderId string into numeric index to consistently assign riders (e.g. Rashmin Salve, Naman Sharma).

❓ TOP 10 EXAMINER QUESTIONS & 30-SECOND ANSWERS
Q1: Where is your database stored?
Answer: "Sir, we use Supabase Cloud Database (PostgreSQL) for real-time order sync and hotel partner accounts. For instant client-side persistence like cart state and sessions, we use browser LocalStorage."
Q2: How does Python backend communicate with React frontend?
Answer: "Sir, server.py runs an HTTP REST API server on port 5000. React sends fetch() requests to endpoints like /api/dishes and /api/orders. CORS headers are configured in Python to prevent security blocks."
Q3: How does category filtering work on the Menu page?
Answer: "Sir, we use React's useMemo hook in menu.tsx. When a user selects a category like Biryani (cat=biryani), it executes an array .filter() on data.ts instantly without re-rendering the whole page."
Q4: How do you assign delivery riders to orders?
Answer: "Sir, in orders.tsx we built a string hashing algorithm getRiderForOrder(orderId). It converts the Order ID into a numeric index using bitwise shifting to assign a rider consistently from our pool."
Q5: Is your payment gateway real or simulated?
Answer: "Sir, it is an interactive Razorpay Test Mode simulation in checkout.tsx. It supports test UPI IDs, card validation, and Cash on Delivery with full receipt generation."
Q6: How does the 3D Spin & Win Fortune Wheel work?
Answer: "Sir, in rewards-modal.tsx we calculate random degree rotations (rotation + 1440 + prizeIndex * 60) with CSS cubic-bezier transitions to simulate realistic 3D wheel physics."
Q7: How does the AI Support Chatbot handle voice commands?
Answer: "Sir, it uses the browser's native Web Speech API — webkitSpeechRecognition for speech-to-text input and speechSynthesis for text-to-speech voice output."
Q8: What is the difference between Customer Login and Hotel Login?
Answer: "Sir, Customer Login allows users to view order history and saved addresses, while Hotel Login (/hotel/login) grants access to the Hotel Partner Dashboard to manage dish availability and order progress."
Q9: Why did you choose React + Vite instead of plain HTML?
Answer: "Sir, React provides component-based architecture and state management, while Vite ensures instant hot module reloading, superfast build performance, and TypeScript type safety."
Q10: How do you handle dark mode styling?
Answer: "Sir, we use custom Tailwind CSS design tokens with glassmorphism effects, HSL tailwind colors, and backdrop-blur overlays to create a sleek dark theme."
