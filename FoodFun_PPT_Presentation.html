Tech Stack & USP

Web Application Technologies Used

  • Frontend Web: React 19, TypeScript, TanStack Router
  • AI Assistant: Floating AI Delivery Support Bot Engine
  • Styling & Motion: Tailwind CSS, Glassmorphic Design, SVG Engine
  • Backend API: Python 3.11 (FastAPI / Flask server.py)
  • Server Engine: TanStack Start / Nitro SSR Engine
  • Database & Auth: Supabase Database SDK + Local Persistence Store
  • Payments & Icons: Razorpay Sandbox, Lucide React Icons

Existing Websites vs Food Fusion USP

  • Existing Food Ordering Websites (Zomato / Swiggy):
    • Restricted to 1 hotel per order (double delivery fees).
    • Manual bill calculations during group dining.
    • Static support forms with delayed resolution.
  • Food Fusion Website USP:
    • Multi-Hotel Single Cart: Order from 2+ hotels in 1 checkout.
    • AI Group Room & QR Code: Automated bill splitter per member.
    • AI Delivery Support Chatbot: Instant automated assistance.
    • Interactive 3D Spin Wheel: Instant coupon unlocks.

Food Fusion – Key Unique Features & Innovations

🍕 Multi-Hotel Single Cart Engine

Combine dishes from multiple partner restaurants in 1 single web checkout. Automatically calculates combined delivery savings (saves ₹39+ per extra hotel).

🤖 AI Delivery Support Chatbot

Floating interactive AI assistant (Food Fusion AI Delivery Assistant) providing real-time order tracking, coupon assistance, and instant query resolution.

👥 AI Group Order Room & QR Bill Splitter

Generates 4-digit room code (FF-ROOM-9821) and SVG QR code. Friends scan QR to join, add items, and view individual bill splits in real-time.

🎡 Gamified 3D Vector Fortune Wheel

Interactive 3D SVG spin wheel with food sticker emojis (🎁, 🎟️, ⚡, 🛵, 🍕, 💰). Enforces 1 daily spin limit + +1 bonus spin awarded on every food order.

🔍 Double-Click 300% HD Image Zoom Lightbox

Double-clicking food dish thumbnails opens a full-screen Lightbox with 300% HD zoom controls (Zoom In, Zoom Out, Reset) and 1-click cart addition.

🥦 Instant Pure Veg vs Non-Veg Dietary Mode

One-click instant theme transformation filtering vegetarian items with green Pure Veg badges and 1000px Ultra-HD photography.
